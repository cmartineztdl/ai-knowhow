# AI Know-How

> A practical, developer-first course to understand and leverage AI in day-to-day coding.

Welcome to **AI Know-How**, a self-paced, theoretical and practical course designed to help developers build a complete mental model of Large Language Models (LLMs) and how to effectively integrate them into modern applications. The course uses JavaScript/TypeScript and focuses on interacting with leading models from OpenAI, Anthropic, and other top-tier providers.

## 📚 Course Structure

The repository is organized to provide a seamless learning experience, starting with theory and culminating in hands-on code:

- **[`/docs`](./docs/COURSE_OUTLINE.md)** — Theory, core concepts, and detailed explanations of how AI models work.
- **[`/exercises`](./exercises/)** — Practical coding challenges with missing pieces or intentional bugs for you to solve and practice what you've learned.
- **[`/solutions`](./solutions/)** — Complete and optimal code solutions to the exercises for your reference.
- **[`/tools`](./tools/)** — Reusable CLI utility scripts created along the way to interact with AI models.
