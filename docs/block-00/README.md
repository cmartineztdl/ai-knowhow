# Block 0 — Foundations: How LLMs Actually Work

> Before using AI tools effectively you need a mental model of what is happening under the hood.

## Prerequisites

None — this is the starting block.

## Topics

1. [Tokenization & Embeddings](01-tokenization-and-embeddings.md) — BPE, sub-word tokens, vector spaces
2. [Transformer Architecture](02-transformer-architecture.md) — Attention, self-attention, positional encoding
3. [Pre-training vs Fine-tuning](03-pre-training-vs-fine-tuning.md) — Base models, RLHF, instruction tuning
4. [Context Windows & Memory](04-context-windows-and-memory.md) — Token limits, chunking strategies, context management
5. [Inference Parameters](05-inference-parameters.md) — Temperature, top-p, frequency penalty, stop sequences
6. [Model Landscape](06-model-landscape.md) — GPT-4o, Claude 3.5, Gemini, open-source models

## What You'll Learn

After completing this block you will understand the core machinery behind every LLM-powered tool you use. You won't need to train models yourself, but you'll know _why_ a prompt behaves the way it does, why context limits matter, and how to pick the right model for a task.
