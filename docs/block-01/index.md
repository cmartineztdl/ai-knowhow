# Block 1 — Talking to Models: APIs & SDKs

> Hands-on interaction with LLM APIs from JavaScript/TypeScript.

## Prerequisites

- [Block 0 — Foundations: How LLMs Actually Work](../block-00/index.md) — understanding tokens, models, and inference parameters

## Topics

1. [OpenAI API](01-openai-api.md) — Chat completions, streaming, function calling
2. [Anthropic API](02-anthropic-api.md) — Messages API, system prompts, tool use
3. [Authentication & Key Management](03-authentication-and-key-management.md) — Environment variables, secret rotation, `.env` best practices
4. [Token Counting & Pricing](04-token-counting-and-pricing.md) — `tiktoken`, estimating costs before calling
5. [Streaming Responses](05-streaming-responses.md) — SSE, chunked transfer, real-time UX
6. [Error Handling & Retries](06-error-handling-and-retries.md) — Rate limits, exponential backoff, circuit breaker patterns

## What You'll Learn

After completing this block you will be able to call the OpenAI and Anthropic APIs from TypeScript, handle authentication securely, estimate costs before making calls, stream responses for real-time UIs, and build resilient systems with proper error handling and retry logic.
