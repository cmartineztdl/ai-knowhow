# Block 2 — Prompt Engineering

> The art and science of getting the output you actually want.

## Prerequisites

- [Block 0 — Foundations: How LLMs Actually Work](../block-00/README.md) — understanding tokens, models, and inference parameters
- [Block 1 — Talking to Models: APIs & SDKs](../block-01/README.md) — calling LLM APIs from TypeScript

## Topics

1. [Zero-Shot, Few-Shot, Chain-of-Thought](01-zero-shot-few-shot-chain-of-thought.md) — Prompting strategies and when to use each
2. [System vs User vs Assistant Roles](02-system-vs-user-vs-assistant-roles.md) — Role architecture, persona shaping
3. [Output Formatting](03-output-formatting.md) — JSON mode, structured output, schema enforcement
4. [Prompt Templates & Variables](04-prompt-templates-and-variables.md) — Dynamic prompt construction, template engines
5. [Guardrails & Validation](05-guardrails-and-validation.md) — Input sanitization, output validation, refusal handling
6. [Prompt Versioning](06-prompt-versioning.md) — Tracking prompt changes, A/B testing prompts

## What You'll Learn

After completing this block you will be able to select the right prompting strategy for any task, design effective role architectures, enforce structured output formats, build reusable prompt templates, validate both inputs and outputs for safety, and manage prompt evolution with versioning and A/B testing.
