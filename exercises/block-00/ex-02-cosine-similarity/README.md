# Exercise 02: Implement Cosine Similarity

## Objective

Implement the `cosineSimilarity` function that measures how similar two embedding vectors are. This is the fundamental operation behind semantic search and RAG systems.

## What You Need to Do

1. Implement the `dotProduct` function
2. Implement the `magnitude` function
3. Implement the `cosineSimilarity` function using the helpers above

## Hints

- Hint 1: The dot product is the sum of element-wise products of two vectors
- Hint 2: Magnitude is the square root of the dot product of a vector with itself
- Hint 3: Cosine similarity = dot(a, b) / (magnitude(a) \* magnitude(b))
