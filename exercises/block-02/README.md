# Block 2 Exercises — Prompt Engineering

> Hands-on exercises to reinforce your understanding of prompt engineering techniques.

## Setup

```bash
cd exercises/block-02
npm install    # from repo root
npx vitest run # run all tests (they should FAIL initially)
```

## Exercises

| #   | Exercise                         | Difficulty | Topic                                 |
| --- | -------------------------------- | ---------- | ------------------------------------- |
| 01  | Build a Prompt Strategy Selector | Easy       | Zero-shot, few-shot, chain-of-thought |
| 02  | Craft a System Prompt Builder    | Easy       | System vs user vs assistant roles     |
| 03  | Enforce Structured Output        | Medium     | Output formatting                     |
| 04  | Build a Template Engine          | Medium     | Prompt templates & variables          |
| 05  | Implement Input Guardrails       | Hard       | Guardrails & validation               |

## How It Works

Each exercise has:

- `src/index.ts` — Code with bugs or `TODO` stubs for you to fix
- `__tests__/index.test.ts` — Vitest tests that verify your solution
- `README.md` — Instructions, hints, and context

Fix the code in `src/index.ts` until all tests pass. Don't modify the test files!
